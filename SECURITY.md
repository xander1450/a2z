# Security Policy

## Supported Versions

- Node.js 20.x
- Next.js 13.x
- TypeScript 5.x

## Reporting a Vulnerability

Please report any security vulnerability by emailing **security@yourdomain.com** with a clear description of the issue, steps to reproduce, and potential impact. We aim to respond within 48 hours and will work with you to resolve the issue.

## Disclosure Timeline

- **Day 1-2**: Acknowledge receipt and begin investigation.
- **Day 3-7**: Provide a status update and initial fix plan.
- **Day 8+**: Release a patch and update the repository with a security advisory.

## Security Practices

- Regular dependency updates via `npm audit`.
- Strict Content Security Policy (CSP) headers.
- Use of HTTPS for all network traffic.
- Server‑Side Rendering (SSR) to minimize client‑side attack surface.
